# 阅读与旅行模块优化设计

## 目标

- 阅读区 8 本书全部展示真实封面，不再使用模拟图文封面。
- 旅行区以可旋转的 3D 世界地球仪展示 28 个去过的地点。
- 删除现有抽象地图和下方地点表格，保持页面结构简洁。

## 阅读区

- 为 8 本书准备本地封面资源，HTML 不引用远程图片。
- 统一封面比例、圆角、阴影和悬停动效；图片使用固定宽高、懒加载和异步解码。
- 图片加载失败时显示书名文字占位，避免空白卡片。
- 保留现有书名、作者和分类信息。

## 旅行区

- 使用 Globe.gl，通过 CDN 加载运行库和世界行政区 GeoJSON。
- 地球采用深墨蓝海洋、冰灰陆地和细弱边界线，延续网站蓝色与粉色强调色。
- 28 个地点按经纬度显示发光点：中国大陆、香港和澳门使用蓝色，巴厘岛使用粉色。
- 鼠标悬停或键盘聚焦显示地点名称；点击地点时平滑转向该位置。
- 地球默认缓慢自转。用户拖动时暂停，交互结束后延迟恢复。
- 支持鼠标拖拽、滚轮缩放和移动端触摸，限制缩放范围以防迷失视角。
- `prefers-reduced-motion: reduce` 下关闭自动旋转和过渡动画。
- CDN 或 GeoJSON 加载失败时显示简洁错误提示，不影响页面其他模块。

## 布局与文案

- 地球仪居中占据旅行区主要视觉空间，外层使用低对比度轨道线与柔光形成“夜航”氛围。
- 保留目的地数量摘要和一句操作提示，不再显示城市表格。
- 桌面端地球最大宽度约 900px；移动端随容器缩放，保留触摸操作空间。

## 数据

- 地点数据集中维护在 `script.js`，每项包含名称、地区、纬度、经度和强调类型。
- 页面语义文本说明共有 28 个目的地，即使 WebGL 不可用也能获知模块内容。

## 验证

- 自动检查 8 张真实封面均存在、尺寸合规且全部由 `<img>` 渲染。
- 自动检查旅行地点数量为 28、旧地点表格已删除、Globe 初始化和降级提示存在。
- 检查 JavaScript 语法、资源路径、响应式布局、键盘焦点和减少动态效果。
- 使用桌面与移动视口截图，核对地球尺寸、书封裁切、文字溢出和控制台错误。
