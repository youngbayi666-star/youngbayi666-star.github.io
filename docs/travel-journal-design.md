# 旅行区：个人旅行手记

## 设计方向

使用 ui-ux-pro-max 的 `minimal editorial portfolio --domain style`、`dragging movements --domain ux` 和 `responsive canvas resize --stack threejs` 检索，采用留白、清晰网格、克制颜色和拖动替代操作的建议。保持本站字体与全局内容宽度。

- 暖白纸色底，与深蓝世界地球形成层次；国内地图采用统一蓝灰色。
- 根据用户反馈，世界与中国使用同一个深蓝地图画框，以“世界 → 中国足迹”标签切换，避免两张独立地图的割裂感。桌面左侧说明和操作、右侧地图；768px 及以下纵向排列，每次只展示当前视角。
- 28 个旅途坐标、2 个国家、27 个国内地点沿用现有数据。
- 金色高亮地球上到访的国家；国内地图用蓝色标记到访地点，棕金色标记学习生活地点。
- 国家按钮提供拖动以外的探索方式；国内下拉框便于触屏与键盘选择，联动地图高亮和经纬度。
- “走近中国”进入国内视角；标签支持方向键、Home/End 及明确焦点管理。隐藏视图不参与键盘导航，国内选择在返回时保留。
- 地球默认静止，主动操作才移动；减少动画设置下视角即时切换。禁用滚轮缩放以保持页面滚动自然。
- 保留地图数据加载失败提示，按钮在地图就绪后启用。

## 验证

`node tests/site-audit.mjs`、`node --check script.js`。

`tests/travel-design-check.cjs` 使用 Playwright 检查 1440、768、390、320px：视角切换与隐藏状态、27 个地点、下拉选择与地图高亮同步、Enter 选择、方向键旋转、国家按钮、画布边界及脚本错误。可使用 `BROWSER_CHANNEL=msedge` 和 `SITE_URL` 指定浏览器与网址。

截图输出到忽略提交的 `artifacts/travel-journal-*.png`，截图时隐藏固定导航以免长图中重复遮挡。
