# Living Index 个人网站设计方案

日期：2026-07-10

网站所有者：杨俊逸（Junyi Yang）

定位：可长期维护和持续生长的个人品牌主页

## 1. 项目目标

网站用于长期呈现杨俊逸的工作、学业、项目成果、旅行、阅读和当下状态。它不是简历的网页复刻，而是一个有清晰结构、真实内容与人格辨识度的个人索引。

网站需要同时做到：

- 让首次访问者快速理解杨俊逸的核心背景与能力；
- 让教育、工作、阅读和旅行共同构成完整的人物形象；
- 使用真实 Logo、书封面和人物素材增强可信度与视觉密度；
- 在素材尚未补齐时仍保持完整，不使用虚构内容或廉价占位图；
- 保持零构建、易维护、可直接部署到 GitHub Pages。

## 2. 核心概念

设计概念为 **Living Index：持续生长的个人索引**。

个人签名“往前走，别回头”同时作为内容和设计规则：页面中的主线始终向下或向右延展；时间与地点从过去走向 `Now`；箭头、坐标、年份和索引线共同表达持续前进。

英文辅助表达为：

> Keep moving forward.

它只用于少量注释，不取代中文签名。

## 13. 视觉系统

### 配色

- 冷雾白 `#F3F6FA`：主背景
- 深墨黑 `#101318`：文字与结构
- 前进蓝 `#246BFD`：教育、工作、链接与索引线
- 生命粉 `#FF4D8D`：旅行、阅读和生活细节
- 雾灰蓝 `#D8E1EC`：辅助层级与卡片底色

所有机构 Logo 默认转为墨黑或低饱和灰，悬停时恢复部分原色。不得改变 Logo 比例、裁切主体或破坏安全留白。

### 字体

- 英文展示标题：宽体、重字重无衬线；
- 中文标题：现代黑体；
- 正文：清晰的中文无衬线；
- 年份、地点和坐标：等宽字体。

字体必须设置可靠的本地回退，不因在线字体加载失败而破坏布局。

### 标志性元素

贯穿页面的 Living Index 索引线显示当前章节、年份与地点。它是全站唯一主要装饰性动作，其他区域保持克制。

## 14. 素材规则

优先使用官方、用户提供或具有明确来源的素材：

- 湖南大学与港中深官方校徽；
- 北京大学长沙计算与数字经济研究院和字节跳动标识；
- 期刊、竞赛和 CCF 官方标识；
- 现有人物抠图；
- 微信读书真实书封面。

找不到高质量官方素材时使用文字徽章，不使用来源不明、低清或带截图背景的 Logo。旅行区在用户未提供照片前不使用网络通用风景图或 AI 占位图。

## 15. 动效与交互

动效集中在三处：

1. 首屏姓名、人像和签名依次进入；
2. Living Index 索引线随滚动向前延展；
3. 旅行地图的方向线缓慢绘制。

其他元素只使用轻微位移、透明度或颜色变化。系统开启 `prefers-reduced-motion` 时关闭非必要动画。

交互包括：

- 锚点导航与当前章节高亮；
- 移动端可用菜单；
- 地图节点悬停或聚焦提示；
- 微信账号复制与状态反馈；
- 书封面和 Logo 的低饱和到局部原色变化。

不保留静态时间、无功能语言切换、伪项目箭头或其他不可操作控件。

## 16. 技术架构

继续使用零构建静态网站：

```text
personal-site/
├─ index.html
├─ styles.css
├─ script.js
├─ assets/
│  ├─ portrait/
│  ├─ logos/
│  ├─ books/
│  └─ icons/
└─ docs/superpowers/specs/
```

核心内容直接存在语义化 HTML 中，JavaScript 只负责渐进增强。关闭 JavaScript 后，所有主要文字、联系方式和成果仍可阅读。抽象地图采用内联 SVG，以便响应式布局、键盘访问和视觉统一。

## 17. 响应式与无障碍

- 桌面使用 12 列布局和纵向索引；
- 平板减少装饰层级，保留双栏结构；
- 手机改为单列叙事，标题不得横向溢出；
- 可交互元素提供明显键盘焦点；
- 地图节点具有可读标签；
- 图片提供准确替代文本；
- 颜色对比满足正文可读性；
- 支持 `prefers-reduced-motion`。

## 18. SEO 与分享

第一版包含：

- 准确页面标题和描述；
- canonical 地址在正式 GitHub Pages 地址确定后补充；
- Open Graph 标题、描述和分享图；
- favicon；
- 人物、教育、工作和成果相关的结构化语义。

在正式域名未确定前不得写入猜测地址。

## 19. 验证标准

实现完成后必须验证：

- 本地服务器返回成功且无资源 404；
- 桌面 1440px、平板 768px、手机 390px 无横向溢出；
- 导航、移动菜单、地图节点和复制微信功能可用；
- 关闭 JavaScript 时核心内容可读；
- 键盘可以访问所有交互元素；
- 减少动画模式生效；
- Chrome、Edge、Safari 和 Firefox 最新版布局可接受；
- 生成桌面、平板和手机截图进行视觉复核；
- 不存在无功能按钮、虚构链接和未标注占位内容。

## 20. 范围边界

第一阶段只实现单页个人网站，不包含：

- 博客后台或数据库；
- 登录、评论和用户系统；
- 自动同步微信读书；
- 自动更新旅行或 `Now` 数据；
- 独立项目详情页；
- 中英文双语内容。

这些能力只有在真实内容和维护需求出现后再扩展。
