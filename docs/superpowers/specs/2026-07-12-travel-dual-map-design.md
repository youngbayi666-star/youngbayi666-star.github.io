# 阅读悬停与旅行双地图设计

## 目标

- 书籍封面悬停时恢复真实色彩并轻微提亮。
- 旅行区改为左侧世界地球、右侧中国地图的双地图布局。
- 世界地球只高亮到访国家；中国地图展示境内具体到访地点。

## 阅读区

- 默认封面保持现有灰度视觉。
- 悬停或键盘聚焦书卡时，图片恢复完整饱和度、略微提亮并放大约 `1.02` 倍。
- 卡片外框负责上浮与阴影，图片自身负责色彩变化，避免父子滤镜冲突。
- `prefers-reduced-motion: reduce` 下取消位移和缩放，仅切换色彩。

## 旅行区布局

- 桌面端使用约 `46% / 54%` 左右双栏；移动端按地球、中国地图上下排列。
- 左侧标题为世界尺度，右侧标题为中国尺度，两者共享同一旅行章节标题和简短说明。
- 删除当前单一居中地球布局，不恢复地点表格。

## 世界地球

- 继续使用固定版本 Globe.gl 和 Natural Earth 国家边界。
- 海洋采用明亮蓝色，普通陆地采用低饱和鼠尾草绿与沙岩色，边界使用半透明浅色。
- 只高亮中国和印度尼西亚，使用珊瑚金强调色，并展示“中国 / CHINA”和“印度尼西亚 / INDONESIA”名称。
- 不在地球上显示城市点；保留拖动旋转、有限缩放、自动缓慢旋转和减少动态效果支持。
- 香港、澳门归入右侧中国地图，不作为国家高亮。

## 中国地图

- 使用阿里 DataV `100000_full.json` 真实省级 GeoJSON 绘制中国轮廓和省界。
- 使用 SVG 地理投影进行自适应绘制，避免引入第二套重型地图运行库。
- 省份以低饱和绿色、沙色和浅蓝色交替，整体保持统一而非彩虹配色。
- 显示 27 个中国境内到访地点；深圳、长沙为较大主节点，香港、澳门为粉色节点。
- 默认仅展示重点城市标签，其他地点在悬停、键盘聚焦或点击时显示名称与地区。
- 珠三角、长三角等密集区域使用小半径节点和动态提示，避免标签永久重叠。
- 地图加载失败时显示可读提示，不影响地球和页面其他模块。

## 可访问性与验证

- 中国地图节点可键盘聚焦，并提供地点名称和地区的无障碍标签。
- 自动检查到访国家恰好为中国、印度尼西亚，境内地点恰好为 27 个。
- 自动检查书封悬停规则直接作用于图片，旧单地球全宽布局已移除。
- 桌面和移动端浏览器检查 WebGL、SVG、中国数据加载、横向溢出、控制台错误和截图布局。
