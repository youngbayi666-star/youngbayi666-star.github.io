# Living Index 严格响应式整改规范

## 目标

保留 Living Index 的冷灰、前进蓝与生活粉视觉识别，同时修复图片传输过大、低清封面被放大、标题尺度失控、卡片留白僵硬和断点规则互相覆盖的问题。

## 资源规范

- 首屏头像提供 480、800、1200 三档 WebP；浏览器通过 `picture/srcset` 按视口选择，不再向手机发送 1500×2250 原始 PNG。
- 学校与企业标识裁切透明留白后输出适合 2× 显示的 WebP，单文件不超过 80KB。
- 所有 `img` 明确声明 `width`、`height`；非首屏图片启用 `loading="lazy"` 与 `decoding="async"`。
- 低于 200px 宽的书封不得铺满卡片。能获得清晰封面则替换；否则使用统一的编辑式文字封面，不伪造高清图片。
- 删除新版页面不再引用的旧图，避免仓库中同时保留两套视觉资产。

## 版式规范

- 内容最大宽度 1180px；桌面、平板、手机使用同一套间距比例。
- 首屏标题桌面上限 7.2rem，手机上限 4.6rem；板块标题桌面上限 5.2rem，手机上限 3.6rem。
- 教育卡、经历卡和阅读卡不使用固定最小高度填充版面；内容决定高度，同行卡片由网格自然对齐。
- 768px 以下采用单列叙事；书架在 520px 以下保持双列，但封面和文字必须分别受控，不再被前序单列规则意外覆盖。
- 旅行地图保留横向探索，但地图画布与滚动容器必须有明确高度、提示和边界，页面本身不得产生横向滚动。

## 验收标准

- 自动审计校验响应式图片、尺寸属性、懒加载、资源体积和唯一断点契约。
- 在 1440×900、1024×768、768×1024、390×844 下逐板块截图。
- 所有视口均无页面级横向溢出、标题裁切、图片越界、卡片互相覆盖和不可解释的大面积空白。
- 首屏图片清晰，书封不被低清放大，Logo 比例一致且不因原图透明留白产生视觉偏移。
